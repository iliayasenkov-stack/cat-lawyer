# Cat Lawyer

Сайт юридического информационного помощника по законодательству Российской Федерации.

## Локальный запуск

Откройте `index.html` в браузере. Для восстановления страницы из исходного сжатого файла выполните:

```bash
node build.mjs
```

## Публикация на Cloudflare Pages

- Framework preset: None
- Build command: `node build.mjs`
- Build output directory: `.`

Страница автоматически восстанавливается из `site.html.gz.b64`. Статические изображения находятся в `assets/`.

## Возможности интерфейса

- адаптивная главная страница Cat Lawyer;
- юридический чат с уточняющими вопросами;
- тарифы 199 / 499 / 999 ₽;
- учебный раздел с мини-тестом;
- профиль и история обращений.

## Технические примечания

Для генерации ответов через языковую модель используется Cloudflare Workers AI. Серверная авторизация и постоянное хранение данных работают через Cloudflare D1.

Сервис носит информационный характер и не заменяет консультацию юриста. Перед применением рекомендаций необходимо проверять действующую редакцию законодательства и обстоятельства конкретного дела.
