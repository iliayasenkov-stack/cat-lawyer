# Cat Lawyer

Демонстрационный сайт юридического помощника на русском языке.

## Локальный просмотр

Откройте `index.html` в браузере. Для восстановления исходного файла из репозитория выполните:

```bash
node build.mjs
```

## Публикация на Cloudflare Pages

В настройках Pages выберите подключённый GitHub-репозиторий и укажите:

- **Framework preset:** None
- **Build command:** `node build.mjs`
- **Build output directory:** `.`

Скрипт создаёт `index.html` из исходного сжатого архива `site.html.gz.b64`.

## Что работает в демоверсии

- главная страница, описание сервиса и тарифы 199 / 499 / 999 ₽;
- демонстрационный юридический разбор по нескольким типовым категориям;
- локальная история вопросов;
- профиль пользователя и выбор тарифа;
- отзывы и форма поддержки.

Данные демоверсии хранятся в localStorage браузера и не синхронизируются между устройствами.

## Перед полноценным запуском

Нужны серверная часть и база данных, настоящая авторизация, AI-модуль с поиском по официальным источникам законодательства РФ и проверкой редакций норм, платёжный провайдер, поддержка, модерация, админ-панель и меры соответствия 152-ФЗ.

**Важно:** демонстрационные юридические ответы не являются полноценной AI-консультацией и требуют проверки перед использованием. Оплата, серверное хранение и настоящая поддержка пока не подключены.
