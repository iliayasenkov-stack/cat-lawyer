Политика конфиденциальности

Cat Lawyer обрабатывает только данные, необходимые для работы сервиса: имя и электронную почту аккаунта, данные сессии, историю обращений и выбранный тариф.

Для чего используются данные

Для регистрации и входа, сохранения истории консультаций, работы личного кабинета и предоставления функций сервиса.

Что не следует отправлять

Не передавайте через чат паспортные данные, банковские реквизиты, пароли, коды подтверждения и другие сведения, раскрытие которых может причинить вред.

Хранение и защита

Пароли хранятся не в открытом виде. Сессионные токены хранятся в виде хеша. Данные размещаются в инфраструктуре, используемой сервисом.

Права пользователя

Пользователь может прекратить использование аккаунта и обратиться к владельцу сервиса по опубликованному каналу связи для вопросов об обработке данных.

Перед публичным коммерческим запуском этот документ должен быть проверен с учётом фактического оператора персональных данных, инфраструктуры и требований применимого законодательства.
